## English

**MarCode** is a desktop application designed to help beginners learn Python interactively. You can read lessons, write code, and get real-time feedback without setting up a complex IDE.

### Features
* **Built-in Editor:** Python code editor with syntax highlighting.
* **Live Execution:** Run your code on the fly and see the output instantly.
* **Challenge System:** Earn points by solving specific lesson tasks.
* **Multi-Language:** Supports English, Persian, and Kurdish.
